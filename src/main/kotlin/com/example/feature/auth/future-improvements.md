# Authentication — Future improvements

Το αρχείο καταγράφει βελτιώσεις που έχουν συζητηθεί αλλά **δεν ανήκουν στο scope της alpha έκδοσης**.

## Περιορισμός κοινής χρήσης λογαριασμών

### Πρόβλημα

Ένας ονομαστικός χρήστης μπορεί να είναι συνδεδεμένος από το Android στο πεδίο, ενώ άλλο άτομο χρησιμοποιεί τα ίδια credentials από το web. Το backend βλέπει τον ίδιο χρήστη και δεν μπορεί από μόνο του να αποδείξει ότι πρόκειται για δύο διαφορετικά φυσικά πρόσωπα.

### Πιθανές μελλοντικές βελτιώσεις

- Ξεχωριστή καταγραφή συσκευών και sessions με `session_id`, `device_id`, `device_type`, `device_name`, `last_seen_at` και `revoked_at`.
- Πολιτική έως μία ενεργή web συνεδρία και μία ενεργή Android συσκευή ανά χρήστη.
- Ειδοποίηση στο Android όταν γίνεται login από νέο browser ή νέα web συσκευή.
- Έγκριση νέας web συσκευής μέσω Android push notification ή OTP.
- Trusted devices με περιορισμένη διάρκεια ισχύος.
- Οθόνη ενεργών συσκευών και δυνατότητα ανάκλησης συγκεκριμένου session.
- Ενέργεια «Αποσύνδεση από όλες τις συσκευές».
- Υποχρεωτικό 2FA ή step-up authentication για ευαίσθητες ενέργειες.
- Audit log που καταγράφει `user_id`, `session_id`, πλατφόρμα, IP, χρόνο και ενέργεια.
- Ανίχνευση ύποπτης ταυτόχρονης χρήσης, χωρίς αυτόματο αποκλεισμό μόνο βάσει IP ή γεωγραφικής θέσης.
- Ρητή πολιτική ότι οι λογαριασμοί είναι ονομαστικοί και δεν μεταβιβάζονται.

Τα παραπάνω μειώνουν και κάνουν ανιχνεύσιμη την κοινή χρήση λογαριασμών, αλλά δεν μπορούν να την αποτρέψουν απόλυτα όταν δύο άτομα συνεργάζονται σκόπιμα.

## Απόφαση για την alpha

- Δεν θα προστεθεί device approval, 2FA, heartbeat ή concurrent-session enforcement.
- Το web και το Android μπορούν να έχουν ξεχωριστά sessions για τον ίδιο χρήστη.
- Ο ίδιος χρήστης σε web και Android καταλαμβάνει μία χρεώσιμη θέση.
- Το όριο της συνδρομής αφορά ενεργούς ονομαστικούς authentication users ανά εταιρεία και όχι sessions ή συσκευές.
- Η βασική συνδρομή περιλαμβάνει έως 3 ενεργούς χρήστες. Πρόσθετες θέσεις αυξάνουν το επιτρεπόμενο όριο.
