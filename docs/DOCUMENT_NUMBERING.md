# Work Order and Technical Case numbering

Numbers are generated by the backend from the authenticated creator's user record.

- Work Orders use `PrefixWO` and `LastReportNumber`.
- Technical Cases use `PrefixTC` and `LastTCNumber`.
- The generated format is `PREFIX-N`, for example `WO-GP-12` or `TC-GP-7`.
- Counters are independent for every tenant user and are updated atomically.
- Numbers cannot be changed through update requests.

## Frontend

For `POST /fieldreports` and `POST /tickets`, omit `ReportNumber` or `TicketNumber` (sending `null` is also accepted). Use the number returned in the create response.

The authenticated creator must have the corresponding prefix configured. Otherwise the create request returns `400` with an explanatory error.

Bulk and legacy offline synchronization numbering are outside the current scope and keep their existing behavior.
